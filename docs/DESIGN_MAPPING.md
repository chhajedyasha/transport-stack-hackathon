# CrowdWise — Design System Mapping

This document maps every topic from `design.md` (Transit Visual System) to its implementation in **CrowdWise**.

| Topic | Decision | How it appears in CrowdWise | Reason & Justification |
|---|---|---|---|
| **Brand Identity (Name, Logo, Mascot)** | **Reject** | Self-made CrowdWise SVG wordmark and geometric transit-wave mark. No mascots, no cartoon illustrations. | CrowdWise is an original public-utility planner for Delhi, not a clone of Transit. All illustrations and proprietary assets are rejected. |
| **Live Tracking & Countdown Signals** | **Reject** | Scheduled times only (`Leaves 6:00 pm · scheduled`). No countdowns ("arriving in 4 min"), no pulsing live dots, no GPS vehicle breadcrumbs, no GO navigation. | **Data Honesty:** CrowdWise estimates demand from historical conductor ticketing data and GTFS timetables. It does not have live GPS feeds. |
| **Real-time Auxiliary Services (Alerts, Payments, Micromobility)** | **Reject** | No service alert banners, push notifications, fare payment wallets, or bike/scooter share integrations. | Outside the Hackathon scope and dataset specifications. |
| **Proprietary Typography (Puffin Transit)** | **Reject** (Substitute) | Inter (`font-sans`) for primary UI and tabular numerals (`tnum`); Noto Sans Devanagari for Hindi localization (`lang-hi`). | Puffin Transit is proprietary. Inter and Noto Sans provide open, high-legibility typographic hierarchy with WCAG AA compliance. |
| **Colour System** | **Adapt** | Primary: Deep Slate Navy (`#142B3B`) for structure/chrome. Accent/Action: Deep Pine Teal (`#00828A`). Background: Clean warm off-white (`#F7F8F6`). Surface: `#FFFFFF`. Neutral Border: `#DDE2E3`. Fixed Semantic Crowd: Low=`#15803D`, Moderate=`#B45309`, High=`#B91C1C`, Unknown=`#64748B`. | Transit's green primary is rejected because CrowdWise uses green exclusively for "Not crowded". Navy gives an authoritative public transport foundation. All colors exceed WCAG AA contrast (>= 4.5:1). |
| **Typography Hierarchy** | **Adopt** | Large bold numbers for travel duration (`headline-md`/`2xl` tabular nums), tight label rhythm (`label-md` 14px, `label-sm` 12px), sentence case for headings. | Produces the bold, scannable poster-like clarity of transit boards without decorative clutter. |
| **Spacing Scale** | **Adopt** | `xs: 12px`, `sm: 16px/20px`, `md: 24px/32px`, `lg: 48px`. Generous touch padding and clean vertical cadence. | Prevents cramped forms and ensures high touch ergonomics on mobile devices. |
| **Corner Radii** | **Adapt** | `control: 4px`, `panel: 8px`, `badge: 4px`, `chip/button: 9999px` (fully round only for pills and primary CTA). Strict maximum radius of 8px on structural containers. | Matches `design.md`'s rounded friendly utility while adhering to the hackathon constraint of <= 8px on standard panels. |
| **Elevation & Depth** | **Adopt** | Flat utility styling. Zero drop shadows on content cards. Borders (`#DDE2E3`) provide structure. Single subtle elevation (`0 4px 16px rgba(20,43,59,0.08)`) reserved for overlays, popovers, and bottom sheets. | Avoids heavy drop shadows and AI-generated card bloat. |
| **Components (Trip Options)** | **Adopt** | `TransitRow`: Route badge, departure time with `scheduled` label, largest travel duration number, `TimeBreakdownBar`, 3-segment `CrowdStrip`, and expandable details. | Core transit information architecture proven for quick decision-making under time pressure. |
| **Crowd Indicator** | **Adapt** | 3-segment discrete horizontal bar (1/2/3 segments) + plain-language text label (`Not crowded`, `Fairly crowded`, `Very crowded`). Never color alone. Seat-style wording (`Seats available`) only active if API reports verified capacity. | Meets WCAG AA non-color dependency and strictly adheres to data honesty rules. |
| **Map Treatment** | **Adopt** | Leaflet OSM with visible attribution. Route track rendered with high-contrast dual casing (6px navy casing + 3.5px teal fill). Circle markers for stops with boarding/alighting emphasis. No default blue Leaflet pins. | Eliminates Vite asset bundling bugs and provides clean, readable wayfinding. |
| **Layouts (Desktop & Mobile)** | **Adopt** | Desktop (>=1024px): 420px fixed left panel with scrollable options + full-height interactive map. Mobile (<1024px): compact route summary, 35% height map + 3-stage BottomSheet (`peek`/`half`/`full`). | Standard transit layout maximizing map context and list readability simultaneously. |
| **Motion** | **Adopt** | Strictly animate `transform` and `opacity` between 120ms and 280ms using `cubic-bezier(0.2, 0, 0, 1)`. Respects `prefers-reduced-motion` override. | Smooth mobile drawer transitions without distracting animations. |
| **Icons** | **Adapt** | Pure functional icons from Lucide React (`Bus`, `Clock`, `ArrowRight`, `Search`, `SlidersHorizontal`). No icons inside colored circles. No emoji. | Clean, utilitarian wayfinding icons. |
| **Copy Tone** | **Adopt** | Grade 8 plain language, sentence case, no buzzwords ("seamless", "AI-powered"). Factual disclaimers on every screen. | Honest, accessible, commuter-first communication. |
| **Responsive Behaviour** | **Adopt** | Seamless fluid adaptation from 320px minimum width (iPhone SE / budget Android) to 1440px desktop. Search CTA stays visible with virtual keyboard open. | Ensures usability for real Delhi commuters on low-end smartphones. |
